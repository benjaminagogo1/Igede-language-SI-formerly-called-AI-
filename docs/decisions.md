## Decision 001 — Project Repository

**Date:** 2026-10-02

**Decision:** GitHub will be used as the main technical repository for the project.

**Reason:** GitHub provides version control, collaboration, code history, issue tracking and documentation.

**Status:** Approved

---

## Decision 002 — Data Quality First

**Date:** 2026-10-02

**Decision:** The project will prioritize verified and high-quality Igede data rather than simply maximizing the number of sentences collected.

**Reason:** A larger dataset containing incorrect or inconsistent translations could negatively affect later AI development.

**Status:** Approved
