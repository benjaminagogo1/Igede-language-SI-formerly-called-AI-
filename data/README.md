# Data

This directory contains documentation and approved sample data related to the Igede Language AI dataset.

## Important

Raw contributor submissions and personal information should not be committed to this repository.

The main working dataset will be maintained in the project's controlled data workspace/database.

## Dataset Direction

The project supports:

- English → Igede
- Igede → English

## Target

Initial target:

**1,000+ verified sentence pairs**

## Example

| ID | English | Igede | Direction | Category | Verified |

## Data Quality

Before data is considered suitable for AI training, it should go through:

1. Collection
2. Review
3. Cleaning
4. Verification
5. Approval
6. Dataset preparation
