# Igede-language-SI (formerly-called-AI)
A community-driven SI project for preserving, documenting, and developing Igede language technology, including an English ↔ Igede chatbot and translator.

## Preserve • Document • Empower • Through Technology

## About the Project

The Igede Language SI project aims to use technology and Superintelligence intelligence to preserve, document, and make the Igede language more accessible.

The project will collect, organize, verify, and structure Igede language data before using the data to develop language technology.

Our long-term goal is to develop an English ↔ Igede chatbot and translation system.

## Project Goals

- Build a high-quality Igede language dataset
- Collect English ↔ Igede sentence pairs
- Establish a community-driven data collection system
- Create a website for submitting language data
- Validate and clean collected language data
- Build an AI-powered Igede chatbot
- Develop English → Igede and Igede → English translation capabilities
- Integrate the AI system into a web application
- Create a foundation for future Igede NLP research

## Initial Development Strategy

We will develop the project incrementally.

### Phase 1 — Foundation

- Establish the project team
- Create the GitHub repository
- Define dataset format
- Establish data collection guidelines
- Begin collecting Igede sentences
- Build the first website prototype
- Establish database structure

### Phase 2 — Data Collection

- Expand the dataset
- Recruit Igede speakers and contributors
- Verify submitted translations
- Remove duplicates
- Standardize spelling and formatting
- Build a reliable verified dataset

### Phase 3 — AI Prototype

- Build a simple rule-based chatbot
- Test English → Igede responses
- Test Igede → English responses
- Evaluate limitations
- Prepare the dataset for machine learning

### Phase 4 — Machine Learning

- Experiment with NLP/ML approaches
- Investigate suitable Hugging Face models
- Train or fine-tune appropriate models
- Evaluate translation quality
- Improve the chatbot

### Phase 5 — Integration

- Connect the AI system to the website
- Create an API
- Integrate the chatbot/translator
- Add user feedback
- Continue improving the dataset and model

## Team Structure

### Data Lead
Responsible for collecting, organizing, translating, and helping verify Igede language data.

### Web Developer
Responsible for developing the data collection website and connecting it to the backend/database.

### Data Quality & Database
Responsible for cleaning, standardizing, validating, and maintaining the dataset and database.

### Community & Growth
Responsible for recruiting contributors, engaging Igede speakers, and collecting community feedback.

### AI / Chatbot Developer
Responsible for developing the chatbot/translator and eventually integrating machine-learning/NLP technologies.

### Communication Lead
Responsible for team communication, documentation, meetings, progress tracking, and project updates.
