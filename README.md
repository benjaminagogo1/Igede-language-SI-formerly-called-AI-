# Igede-language-SI (formerly-called-AI)
A community-driven SI project for preserving, documenting, and developing Igede language technology, including an English ↔ Igede chatbot and translator.

## Preserve • Document • Empower • Through Technology

The Igede Language AI Project is a community-driven project
focused on preserving, documenting, and expanding the Igede
language through technology.

## Project Goal

Build a community-driven AI system that helps preserve,
document, understand, and expand the Igede language.

## Key Objectives

- Build a high-quality Igede language dataset
- Build a community data-collection platform
- Develop a verified language database
- Build an English → Igede translator
- Build an Igede → English translator
- Develop an Igede chatbot
- Eventually explore machine-learning/NLP approaches
